# Ladies Salon Website

Angular standalone starter for a ladies' beauty salon. **Bloom Beauty Studio** is placeholder branding.

## Run locally
Install Node.js 24.15+ (24.x) and npm, then:
```bash
git clone https://github.com/MuhaddisSaleem/LadiesSalonWebsite.git
cd LadiesSalonWebsite
npm install
npm start
```
Open http://localhost:4200. Production build: `npm run build`.

## Included
- Responsive blush, ivory and plum homepage
- Interactive service category filters
- Bridal package concepts and an about section
- Angular routing and standalone components
- Local SVG artwork; no external image requests

## Salon ideas
Names: Bloom Beauty Studio, Noor Beauty Lounge, Blush & Bloom, Zoya Beauty Atelier.
Services: haircut and styling, hair colour, facials, manicure/pedicure, party makeup and bridal makeup.
Packages: bridal consultation and trial; monthly self-care bundle; party-ready makeup and hair.
Next phases: online appointments, stylist availability, walk-ins, customer profiles, service/package administration and revenue reports.
Potential backend: .NET API and SQL Server.

## Starter limitations
This is a frontend concept, not a live booking system. There is no backend, authentication, appointment persistence, payment integration or admin portal yet.
Replace sample branding, service descriptions and package details with owner-approved content before launch.
Dependency installation was blocked in the creation environment; the production build has not been verified. Run `npm install` and `npm run build` locally. Commit the generated package-lock.json after successful installation.
